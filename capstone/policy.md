# ACME Cloud support policy (v4.2, excerpt)

1. Refunds. Duplicate charges for the same order are always refunded in full to the original payment method. Agents may issue credits up to $100 without approval; larger amounts need a billing lead.
2. Account access. Customers who cannot log in get a password reset sent to the email on file. Never ask for a password, security code or API key.
3. Escalation. Tickets that mention cancellation, legal action or a data breach go to a team lead within one hour. Repeat contacts about the same issue go to a senior agent.
4. Feature requests are logged on the feedback board and acknowledged. No delivery dates.
5. Bugs that take a customer's service down are escalated immediately.
